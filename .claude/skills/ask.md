# /ask - 纯讨论模式 Skill

进入**纯讨论模式**，仅分析和讨论，不执行任何代码。

## 用法

```bash
/ask [你的问题]
```

## 行为规则

在纯讨论模式下，我会：

✅ **会做的事**：
- 📖 分析代码和代码结构
- 💡 提出建议和方案
- 🎯 对比多个解决方案的优缺点
- 📝 提供代码示例（markdown格式展示）
- ❓ 回答问题和概念讨论
- 🧠 头脑风暴和创意思考

❌ **不会做的事**：
- ❌ 执行任何 Bash 命令
- ❌ 修改、创建、删除文件
- ❌ 调用 Edit、Write、Glob、Grep 等工具
- ❌ 请求权限或执行 hooks
- ❌ 实际运行代码

## 何时使用

| 场景 | 示例 |
|------|------|
| 📋 代码审查 | `/ask 这个函数有什么问题？` |
| 🎯 方案设计 | `/ask 怎样重构这个模块？` |
| ❓ 问题诊断 | `/ask 为什么这里会报错？` |
| 💭 概念讨论 | `/ask TypeScript 的泛型怎样理解？` |
| 🔍 学习教学 | `/ask 解释一下这个算法的思路` |

## 退出纯讨论模式

讨论完成后，说以下任何一句来执行建议：
- `好的，现在执行`
- `按你的建议执行`
- `离开 /ask 模式`
- `/execute`

## 示例

```
用户: /ask 这个React组件有性能问题吗？
我: [分析代码，指出问题，提出优化建议，但不修改任何文件]

用户: 能不能改成memo包裹？
我: [展示改写后的代码示例，解释为什么这样好]

   ```jsx
   const MyComponent = memo(({ data }) => {
     // 代码示例
   });
   ```

用户: 好的，现在执行
我: [退出/ask模式，使用Edit工具实际修改文件]
```

## 设置快捷方式

在 `~/.claude/keybindings.json` 中可以添加快捷键：

```json
{
  "bindings": [
    {
      "key": "cmd+shift+a",
      "command": "/ask"
    }
  ]
}
```
