## 一、先定指标（看哪里慢）
- **加载慢**：首屏白屏久、资源加载卡
- **渲染慢**：页面卡顿、滚动掉帧、动画卡
- **交互慢**：点击延迟、输入卡顿、弹窗卡顿
- **内存泄漏**：越用越卡、切页变卡、页面发烫
- ## 二、使用工具采集数据
- ### 浏览器原生工具（最常用）
- **Lighthouse**：综合评分，输出**首屏 FCP、最大内容绘制 LCP、可交互时间 TTI、累积布局偏移 CLS**四大核心指标，直接定位规范问题。
- *Performance**：录制运行时，分析**长任务、主线程阻塞、重排重绘、JS 执行耗时**，识别卡顿根源。
- **Network**：查看请求瀑布流：资源大小、请求数量、加载顺序、TTFB、静态资源 / 接口耗时、是否有大文件、重复请求、未缓存资源。
- **Memory**：监控内存使用，排查**内存泄漏**（常驻内存、GC 频繁、内存持续上涨）。
- **Elements/Rendering**：开启渲染图层，查看**重排 (Reflow)、重绘 (Repaint)** 范围与频率。
- ### 线上监控
- 前端监控平台（Sentry、埋点、自研监控）：查看**真实用户性能数据、异常报错、地域 / 设备 / 网络差异**，区分是局部问题还是全域问题。

- ## 三、第三步：分层逐一排查
  
  按**网络层 → 资源层 → 渲染层 → JS 执行层 → 应用逻辑层**逐层拆解。
- ### 1. 网络层问题（加载阶段首要排查）
- 静态资源：JS/CSS/ 图片 / 字体**体积过大、数量过多**；未开启 Gzip、HTTP 缓存、CDN。
- 接口请求：接口超时、串行请求过多、请求冗余、大数据量返回、跨域 / 代理耗时。
- 网络链路：TTFB 过高、弱网适配差、未做资源预加载 / 懒加载。
- ### 2. 资源与构建层面
- 打包产物：未分包、主包体积过大、无用代码（死代码）未 Tree-Shaking。
- 资源格式：图片未压缩、未使用 WebP/AVIF、大图未懒加载、视频无优化。
- 冗余资源：引入全量第三方库、重复加载脚本、未按需引入。
- ### 3. 渲染层问题（页面卡顿、掉帧核心）
- **重排重绘频繁**：频繁读写 DOM 样式、批量修改 DOM、频繁改变宽高 / 位置属性。
- **层级问题**：大量元素触发图层爆炸，合成层过多占用资源。
- **布局抖动**：JS 循环里交替读取 + 修改 DOM 样式，强制浏览器反复计算布局。
- 全局样式、通配符选择器、深层 CSS 选择器增加样式计算耗时。
- ### 4. JS 主线程阻塞（长任务、交互延迟主因）
- 同步 JS 执行时间过长（超过 50ms 即为长任务），阻塞主线程。
- 大量循环、复杂计算、递归、大数据遍历放在主线程。
- 第三方脚本（埋点、广告、统计）执行耗时高、抢占主线程。
- 定时器 / 事件监听滥用，未及时解绑。
- ### 5. 内存泄漏（页面越用越卡）
- 常见场景：
	- 全局变量过多、闭包未释放引用。
	- DOM 节点脱离文档流但仍被 JS 引用。
	- 定时器、事件监听、监听回调未销毁（路由切换 / 组件卸载未清除）。
	- 大数组 / 大对象常驻内存，无法被 GC 回收。
- ### 6. 业务 & 框架层面（Vue/React 专属）
- React：不必要的重渲染（组件、列表频繁更新）、key 不合理、未使用`memo/useMemo/useCallback`、虚拟列表未做导致大数据列表卡顿。
- Vue：冗余响应式数据、大量 v-if/v-for 混用、未使用虚拟滚动、监听无销毁。
- 路由 / 懒加载：路由未分包、组件未懒加载、首屏加载过多非必要组件。
- ## 四、对应优化方案（排查后配套回答）
  
  简要对应问题说优化方向，不用展开太细：
- 网络 & 资源：压缩资源、Gzip、CDN、合理缓存、图片优化、懒加载、资源预加载。
- 构建优化：分包、Tree-Shaking、按需引入、移除冗余依赖。
- 渲染优化：减少重排重绘、读写 DOM 分离、使用 GPU 加速、简化 CSS 选择器。
- JS 优化：长任务拆分（Web Worker、定时器分片）、减少主线程计算。
- 内存优化：及时解绑监听、清空定时器、切断无用引用、避免全局滥用。
- 框架优化：阻止无效重渲染、大数据列表用**虚拟滚动**、路由懒加载。
- ## 一分钟快速回答
- 排查网页性能我会按**从外到内、从加载到运行**分层排查：
	- 先通过 Lighthouse 拿到 LCP、FCP 等核心性能指标，确定是加载慢还是运行卡顿。
	- 用 Network 分析网络：检查资源大小、请求数量、缓存、接口耗时，解决网络和静态资源问题。
	- 用 Performance 录制页面运行情况，定位主线程长任务、重排重绘、JS 执行阻塞。
	- 借助 Memory 工具排查内存泄漏，重点检查监听、定时器、DOM 引用是否未释放。
	- 结合框架特性，排查组件无效重渲染、大数据列表渲染等问题。
	- 针对性优化后，再次复测指标，验证优化效果。
