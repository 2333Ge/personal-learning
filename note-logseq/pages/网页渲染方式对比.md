- **CSR 客户端渲染**：浏览器空 HTML+JS，前端拿数据渲染。首屏慢、SEO 差、交互强。适合后台系统、SPA。
- **SSR 服务端渲染**：请求时服务器生成完整 HTML 返回。首屏快、SEO 好、服务器压力大。适合电商、资讯、强 SEO 页。
- **SSG 静态站点生成**：构建时预生成所有 HTML，CDN 直接返回。**速度最快、SEO 极佳、零服务器压力**；更新需重构建。适合博客、文档、官网。
- **ISR 增量静态再生**：SSG 增强，构建时生成 + 访问后定时 / 按需重新生成。**静态速度 + 动态更新**，折中最优。适合电商商品页、新闻、中低频更新内容。
- **Streaming SSR 流式 SSR**：服务器分段生成 HTML，边传边显示。**首屏更快、TTFB 更优**，React18+/Next.js 支持。适合长内容、资讯流。
- **RSC React 服务端组件**：组件级渲染，服务端运行、不发客户端 JS。**包体极小、服务端直连数据库**；不能用 useState 等。适合复杂全栈应用。
- **Edge 边缘渲染**：SSR 逻辑部署在 CDN 边缘节点。**延迟更低、就近访问**，Vercel/Cloudflare 支持。适合全球访问、高并发。
- ## 选型
- 后台 / 强交互 → **CSR**
- 博客 / 文档 / 官网 → **SSG**
- 电商 / 资讯 / 需 SEO → **SSR/ISR**
- 长内容 / 追求极致首屏 → **Streaming SSR**
- 大型全栈、减包体 → **RSC**
- 全球高并发、低延迟 → **Edge**
