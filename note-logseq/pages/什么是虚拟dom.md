- 虚拟 DOM 就是用一个普通的 JavaScript 对象，来模拟真实 DOM 节点的结构。
	- 真实 DOM：浏览器渲染出来的页面元素（div、p、span...），很重、属性超多
	- 虚拟 DOM：**轻量的 JS 对象**，只记录标签名、属性、子节点，不涉及浏览器渲染
- ## 虚拟 DOM 的工作流程
- **数据变化 → 生成新的虚拟 DOM 树**
- **Diff 算法对比新旧虚拟 DOM**（找出哪里变了）
- **只把变化的部分更新到真实 DOM**（最小化操作）
- ## 虚拟 DOM 的核心优势
- ### 1.  **性能优化：减少真实 DOM 操作**
- 真实 DOM 非常 “重”，频繁操作会触发大量重排、重绘，非常卡
- 虚拟 DOM 用 **Diff 算法**找到最小变化，**只更新需要改的地方**
- 避免手动频繁操作 DOM，大幅提升渲染性能
- ### 2.  **跨平台能力（最重要优势之一）**
- 虚拟 DOM 本质是 **JS 对象**，和浏览器无关
- 一套代码可以跑在：Web、小程序、React Native (App)、Weex、服务端渲染
- 实现 **“一次编写，多端运行”**
- ### 3.  **声明式编程，开发效率更高**
- 不用手动操作 DOM、不用关心如何更新页面
- 只需要**描述页面长什么样**（数据驱动视图）
- 代码更简洁、易维护、不易出 Bug
