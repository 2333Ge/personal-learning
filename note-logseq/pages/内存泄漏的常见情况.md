- 意外的全局变量：刻意挂载大量数据到 `window` 但忘记清理
	- 严格模式 `'use strict'` 禁止意外全局变量（未使用 `var/let/const` 声明的变量，会自动挂载到 ）`window` 上，**永远不会被回收**
	- 全局变量用完手动置为 `null`
	- 尽量不用全局变量存储大量数据
- 遗忘的定时器 / 延时器：定时器回调里**引用了外部变量 / 组件**，只要定时器不清除，整个作用域都无法回收。
	- 组件销毁 / 页面离开时**清除定时器**
- 未清理的事件监听：DOM 被删除了，但**绑定的事件监听还在**，导致 DOM 无法被回收。
	- 移除 DOM 前先**移除事件监听**
- 闭包滥用：
	- 避免不必要的闭包
	- 不用的闭包引用手动置 `null`
- DOM 引用悬空：你已经从页面删除了 DOM，但**JS 里还存着它的引用**，导致 DOM 内存无法释放。
  ```jsx
  // 保存了 DOM 引用
  const domCache = {
  box: document.getElementById('box')
  };
  - // 页面上删除了 DOM
  document.body.removeChild(domCache.box);
  - // 但 domCache.box 还持有引用 → 内存泄漏
  ```
	- 删除 DOM 后，**手动把引用置为 null**
- 第三方库 / 插件未销毁:ECharts、地图、编辑器、视频播放器等，**创建后没有调用销毁方法**。
	- 组件卸载时调用库的 `dispose()`/`destroy()`
- 缓存未限制大小: 用对象 / Map 做缓存，**只加不删**，无限增长。
	- 设置缓存最大容量
	- 使用 LRU 缓存策略（最少使用淘汰）
	- 定期清理过期缓存
