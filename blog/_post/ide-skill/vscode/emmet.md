# emmet(WIP)

## 介绍

优先看[中文文档](https://yanxyz.github.io/emmet-docs/abbreviations/)

## 常用

Lorem ipsum 生成器：生成假文本，用于测试。e.g.
```
p*4>lorem
```
非 html标签也能使用emmet。e.g.

```shell
#输入
TopicList
# 输出
<TopicList></TopicList>
```
